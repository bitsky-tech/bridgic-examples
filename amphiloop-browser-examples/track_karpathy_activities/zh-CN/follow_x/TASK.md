# 浏览器自动化任务

## 任务描述
抓取 Andrej Karpathy 在 X 上的个人主页近几天发布的帖子，并将其保存到文件中。

1. 先打开 "https://x.com?lang=en"。
2. 检查当前是否在登录页面。如果页面停留在登录界面，则需要与人交互去完成登录。
3. 进入 `/home`，打开 "https://x.com/karpathy"。
   注意：一定不要在未登录状态下访问 "https://x.com/karpathy"，因为这样的话获取不到最新的帖子信息。
4. 从页面下方的 "Posts" 区域依时间倒序获取每一条帖子，直到这些帖子超出指定的时间范围为止，并需不断向下滚动页面以加载更早的帖子。
   注意：跳过带有 "Pinned" 标签的帖子；跳过广告；正确区分 Andrej Karpathy 本人发的帖子与转发的内容。对于转发内容，请务必记录原作者，不能将其错误记录为 Andrej Karpathy 本人发布。
5. 将所有获取到的帖子，以 markdown 格式保存到文件 `x_posts.md` 中。

## 预期输出
`x_posts.md`：按时间倒序保存的、位于指定时间范围内的 Andrej Karpathy X 帖子（markdown 格式），跳过 Pinned 帖子与广告，转发内容需正确记录原作者。

## 备注
- 参数要求：
  - 指定的时间范围（天数）作为生成程序的参数，默认是 7 天。
  - 是否使用有头浏览器，作为生成程序的参数。
- 输出一份 README 文件，说明生成的程序的使用方法。
- 如果检测到未登录，需要人工介入完成登录，程序以较慢频率轮询登录状态。
