# 浏览器自动化任务

## 任务描述
抓取 GitHub 上某个指定代码库在最近若干天内的 releases 发布信息，并进行汇总分析。

1. 根据指定的代码库（`repo_name`）拼接需要抓取的 releases 页面地址：https://github.com/<repo_name>/releases
2. 用浏览器访问拼接好的 releases 页面地址。
3. 按时间倒序读取每一个"发布版本"的信息，包括版本名称、发版时间、版本描述（这一部分是主要信息，内容可能较长）。一直读到发版时间超出了指定的时间范围后停止读取；如果指定时间范围内发布版本数量较多，注意需要翻页继续读取。
4. 把所有这些读取到的信息按顺序以 markdown 格式存放到 `releases_data.md` 文件中。确保该文件确实保存成功了，才进行下一步。
5. 对存放的该代码库的发布版本记录进行总结，并把总结内容以 markdown 格式输出到 `report.md`。总结后的内容力求精炼，不得超过 400 字。**务必**先输出一个概括总结，说明指定时间范围内该代码库维护的主要精力在哪里；然后再对重点发布版本分别做小结，尤其注意要突出重大的特性发布、架构变动以及重大问题修复等内容。

## 预期输出
- `releases_data.md`：按时间倒序汇总的、位于指定时间范围内的发布版本记录（markdown 格式），包含版本名称、发版时间和版本描述。
- `report.md`：不超过 400 字的 markdown 总结报告，先给出整体概括，再对重点版本分别做小结。

## 备注
- 参数要求：
  - 代码库名称 `repo_name` 作为生成程序的参数。
  - 指定的时间范围（天数）作为生成程序的参数，默认是 7 天。
  - 是否使用有头浏览器，作为生成程序的参数。
- 生成一个 README 文件，详细说明生成的程序的用法。
- 验证策略：程序生成后，至少验证 `repo_name="openclaw/openclaw"` 和 `repo_name="bitsky-tech/bridgic-browser"` 两种情况。
