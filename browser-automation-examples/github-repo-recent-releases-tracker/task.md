# 把下面的任务写成代码

## 任务目标
抓取GitHub上某个指定代码库在最近若干天内的releases发布信息，调用`claude -p`进行汇总分析。

## 任务步骤
1. 根据指定的代码库（`repo_name`）拼接需要抓取的releases页面地址： https://github.com/<repo_name>/releases 。
比如，由repo_name="openclaw/openclaw"，得到地址 https://github.com/openclaw/openclaw/releases 。
2. 用浏览器访问拼接好的releases页面地址。
3. 按照时间倒序读取每一个“发布版本”的信息，包括版本名称、发版时间、版本描述（这一部分是主要信息，内容可能较长）。一直读到发版时间超出了指定的时间范围后，停止读取；如果指定时间范围内发布版本数量较多，注意需要翻页继续读取。
4. 把所有这些读取的信息按照顺序以markdown格式存放到`./outputs/releases_data.md`文件中。确保该文件确实保存成功了，才进行下一步。
5. 进入到`./outputs/`目录下。如果进入失败，报错退出。
6. 调用`claude -p`对目录下存放的该代码库的发布版本记录进行总结，并把总结内容以markdown格式输出到`./outputs/report.md`。总结后的内容力求精炼，不得超过400字。**务必**先输出一个概括总结，说明指定时间范围内该代码库维护的主要精力在哪里；然后再对重点发布版本分别做小结，尤其注意要突出重大的特性发布、架构变动以及重大问题修复等内容。请综合所有的要求为`claude -p`撰写恰当的prompt指令。

## 参数要求
 - 代码库名称`repo_name`作为生成程序的参数。
 - 指定的时间范围（天数）作为生成程序的参数。默认是7天。
 - 是否使用有头浏览器，作为生成程序的参数。

## 其他要求
 - 生成一个README文件，详细说明生成的程序的用法.
