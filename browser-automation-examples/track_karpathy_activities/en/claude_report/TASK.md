# Browser Automation Task

## Task Description
Write a Shell script that calls `claude -p` to analyze local data files and produce an analysis report.

1. Analyze the three files `github_activities.json`, `x_posts.md`, and `google_search_results.json` via `claude -p`, and write a Markdown analysis report to `karpathy_report.md`. Construct the `claude -p` prompt so that it follows these requirements:
   - Based on the GitHub information, summarize Andrej Karpathy's major research directions in recent months, his primary areas of focus, and any major findings or theoretical breakthroughs.
   - Based on the X information, summarize Andrej Karpathy's latest updates in recent days: what thoughts he has shared, how they relate to his major research directions, who he interacts with most frequently, etc.
   - Use the Google Search information as supplementary context.

## Expected Output
`karpathy_report.md`: a Markdown analysis report generated by `claude -p`, synthesizing the GitHub, X, and Google Search data into a structured summary covering research directions, recent updates, and supplementary context.

## Notes (optional)
- Output a README file explaining how to use the generated script.
- If any of the three input files is missing, the script should exit with an error and not continue.
