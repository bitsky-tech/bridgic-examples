# 把下面的任务写成代码

## 任务目标
抓取 Andrej Karpathy 在 X 上的个人主页近几天发布的帖子，并将其保存到文件中。

## 任务步骤
1. 首先一定要先打开 "https://x.com?lang=en"。
2. 检查当前是否在登录页面。如果页面停留在登录界面，则提示用户去登录，并以较慢的频率轮询检测登录是否成功。检测到成功后，自动执行下一步。
3. 确认当前页面进入了 `/home`，然后才打开 "https://x.com/karpathy"。注意，一定不要在未登录状态下访问"https://x.com/karpathy"，因为这样的话获取不到最新的帖子信息；也不要在探路过程真正到达"https://x.com/karpathy"之前开始编写代码。
4. 从页面下方的"Posts"区域依时间倒序获取每一条帖子，直到这些帖子超出指定的时间范围为止，并需不断向下滚动页面以加载更早的帖子。
   获取过程需注意：跳过带有"Pinned"标签的帖子；跳过广告；正确区分安 Andrej Karpathy 本人发的帖子与转发的内容。对于转发内容，请务必记录原作者，不能将其错误记录为 Andrej Karpathy 本人发布。
5. 将所有获取到的帖子，以 markdown 格式保存到文件 `../tracking_results/x_posts.md` 中。

## 参数要求
 - 指定的时间范围（天数）作为生成程序的参数。默认是7天。
 - 是否使用有头浏览器，作为生成程序的参数。
